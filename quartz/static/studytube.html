          How to get a free key (about 3 minutes)
          1. Go to console.cloud.google.com and create a project (any name).
          2. Open APIs & Services → Library, search YouTube Data API v3, and click Enable.
          3. Open APIs & Services → Credentials → Create credentials → API key, then copy the key.
          4. Recommended: edit the key, choose Restrict key under API restrictions, and pick YouTube Data API v3. Leave application restrictions on None.
          5. Paste it above. It stays in this browser only.
